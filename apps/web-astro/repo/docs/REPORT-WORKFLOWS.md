# Report workflows

The report system is planned around deterministic inputs and staged editorial work:

```text
chart and timing calculation
-> fact graphs
-> approved life context and supplied frameworks
-> ranked signatures
-> section plan
-> section drafts
-> cross-section synthesis
-> grounding and uncertainty validation
-> brand editing
-> artifact assembly
-> legacy adapter
```

`life-handbook-v1` is a bounded plan. Biography and Human Design sections are omitted unless approved source material is supplied. Timing prose must consume validated timing facts rather than inventing dates.
