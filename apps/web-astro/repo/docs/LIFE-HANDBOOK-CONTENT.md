# Life handbook content contract

The handbook mode is an explicit, high-context product. It can contain technical natal reference, central synthesis, house and planet chapters, aspect wiring, approved biographical context, optional user-supplied symbolic frameworks, applied guidance, deterministic year-ahead timing, appendices, and an operating card.

The system must distinguish astronomical calculation, symbolic interpretation, user-provided biography, and practical synthesis. It must never invent biography or silently calculate an unsupported framework. Sensitive context requires explicit approval for synthesis and is excluded from telemetry.
