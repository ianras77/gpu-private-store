# Editorial workflows

The Mastra runtime exposes versioned workflow boundaries for research, story,
theme take, homepage, social, report, and full-cycle execution. Every request
starts with the BAT source-policy plane; empty or unapproved source results are
returned as weak evidence rather than being filled with model invention.

The current staged adapters expose operational stages and research packet IDs.
Report runs additionally validate and persist source-visible report artifacts.
Story, homepage, and social publication continue through the existing approval
and publishing controls until their live parity qualification is complete.
